 PASSO 1 - Criar conta (5 min)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Abra: https://www.oracle.com/cloud/free/
2. Clique em START FOR FREE (canto superior)
3. Preencha:
   - País: Brazil
   - Nome, email, senha
4. Confirme o email que chegou
5. Adicione cartão de crédito (SÓ pra verificar, NÃO cobra)

⚠️ IMPORTANTE: Oracle cobra R$0. Eles pedem cartão apenas
   pra confirmar que é pessoa real.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 PASSO 2 - Criar o servidor (5 min)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. No painel, clique no menu HAMBURGUER (3 linhas) canto esq.
2. Compute > Instances > CREATE INSTANCE
3. Configure assim:

   ┌── IMAGE ──────────────────────────┐
   │ Click "CHANGE IMAGE"              │
   │ Canonical Ubuntu > Ubuntu 22.04   │
   └───────────────────────────────────┘

   ┌── SHAPE ──────────────────────────┐
   │ Click "CHANGE SHAPE"              │
   │ Select: VM.Standard.A1.Flex       │
   │ OCPU: 4    Memory: 24 GB          │
   └───────────────────────────────────┘

   ┌── STORAGE ────────────────────────┐
   │ Boot volume: 200 GB               │
   └───────────────────────────────────┘

   ┌── SSH KEY ────────────────────────┐
   │ Select: "Generate new key pair"   │
   │ Name: nexusplay                   │
   │ Click: SAVE PRIVATE KEY (.key)    │
   │ ⚠️ GUARDE ESSE ARQUIVO!           │
   └───────────────────────────────────┘

4. Clique em CREATE
5. Espere o status virar "RUNNING" (~2 min)
6. ANOTE O IP PÚBLICO (parece: 129.153.xx.xx)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 PASSO 3 - Abrir porta 5000 (2 min)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Menu: Networking > Virtual Cloud Networks
2. Clique na sua VCN (lista)
3. Clique na SUBNET (nome com "subnet")
4. Aba: Security Lists > Default Security List
5. Clique: ADD INGRESS RULES
6. Preencha:
   - Source CIDR: 0.0.0.0/0
   - Destination Port: 5000
7. Clique: ADD INGRESS RULE

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
